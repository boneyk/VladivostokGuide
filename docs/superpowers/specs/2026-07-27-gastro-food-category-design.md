# Гастро-раздел гида: категория «Еда и гастрономия»

Дата: 2026-07-27
Статус: дизайн утверждён, список заведений получен и разложен (13 мест), флагман выбран — Zuma

## Цель

Добавить в гид по Владивостоку раздел о еде: где поесть туристу, который в городе
впервые. Угол — **практичный гид на все случаи**: завтрак/кофе, ужин-ресторан,
быстро-и-недорого, вечер с музыкой. Основа при этом — местное и характерное
(морепродукты и краб, дальневосточная кухня, паназия).

## Решения

### 1. Формат

Гастро-места живут как **новая, 7-я категория мест** (`CategoryId`), каждое
заведение — отдельная карточка-`Attraction`, как остальные достопримечательности.
Не отдельный тип данных, не только маршрут.

### 2. Модель данных — реюз `Attraction`

Схему `src/data/types.ts` **не меняем**. Карточка заведения ложится на текущий
`Attraction`:

- гастро-специфика («кухня / чек / часы / бронь / адрес / что брать») → `quickFacts`;
- повод и формат → `tags`;
- текст → обычные секции с блоками.

Гипотеза «модель тянет ресторан без изменений» проверяется на карточке-флагмане
(см. Роллаут). Если на практике не хватает — заводим отдельный шаблон/поля; это
единственная открытая архитектурная развилка.

### 3. Категория

| поле | значение |
|---|---|
| `id` | `food` |
| `title` | «Еда и гастрономия» |
| `navLabel` | «Еда» |
| `icon` | 🦀 (краб — символ города; альтернатива 🍽️) |
| `description` | «Где поесть во Владивостоке: морепродукты и краб, паназия, кофейни и джаз-бары — от завтрака до позднего вечера.» |

Порядок — в конец списка категорий на главной (после `leisure`).
Правки: `src/data/types.ts` (union `CategoryId`) и `src/data/categories.ts`.

### 4. Теги-поводы (словарь, откалиброван под список v1)

Раздел один; внутри каждая карточка несёт 1–2 тега-повода, чтобы турист быстро
нашёл нужное. Это обычные `tags`, не подкатегории. Словарь скорректирован по
фактическому списку заведений (см. раздел «Список заведений»):

Активные (есть заведения):

- 🌅 Завтрак / кофе
- 🍽️ Ужин-ресторан
- 🦀 Морепродукты / краб
- 🥟 Паназия / Восток
- ⚡ Быстро и недорого
- 🎷 Бар / вечер с музыкой — *добавлен*: в списке три джаз-бара (Синкопа,
  Жуклевичъ, Контрабанда), им нужен собственный повод
- 🕰️ С историей / атмосфера — *добавлен*: «Не рыдай» (столовая с 1923),
  Жуклевичъ (историческое здание купца)

Зарезервированы (валидный повод, но в списке v1 заведений пока нет — вводим при
пополнении):

- 🌉 Обед с видом
- 🛒 Рынок / за продуктами

### 5. Шаблон `quickFacts` заведения

- 🍴 Кухня
- 💰 Средний чек (напр. «1500–2500 ₽ на человека»)
- 🕐 Часы
- 📞 Бронь (нужна вечером / не нужна / ссылка)
- 📍 Где (район + ссылка на Яндекс/2ГИС)
- ⭐ Брать обязательно (фирменное блюдо)

Секции текста — по паттерну гида (500–700 слов, скилл `vladivostok-guide-card`):
что за место и атмосфера, что заказать, практика/как добраться.

### 6. Роллаут

- **Флагман — Zuma** — сразу `status: 'ready'`, полноценный текст. Пилот, на
  котором проверяем удобство для пользователя и достаточность модели `Attraction`.
  Выбор обоснован: крупнейший паназиатский ресторан Дальнего Востока (с 2011),
  краб / гребешок / морской ёж, топ городских рейтингов — самое узнаваемое
  «визитно-владивостокское» гастро-место и одновременно самый «нагруженный»
  тип карточки (богатое меню, бронь, чек) — хороший стресс-тест модели.
- **Остальные 12** — батчем `status: 'planned'` (бейдж «В планах», заглушка),
  по паттерну `src/data/attractions/planned.ts`. Тексты дописываем поштучно позже.

Заметки по нестандартным карточкам:

- ⚠️ **Контрабанда** — в мае 2026 закрылась на ремонт (обещали вернуться).
  Заводим `planned`, но при написании карточки перепроверяем, открылась ли; если
  нет — держим со статусом-заглушкой и пометкой «временно закрыто».
- ℹ️ **Колодец дракона** — это чайная (чайные церемонии), а не заведение с едой.
  Карточку пишем как гастро-*опыт*, а не «где поесть»: акцент на ритуал/чай, поля
  `quickFacts` адаптируем (вместо «средний чек» — «сеанс/чайная карта»).
- **ProКофий / «Не рыдай» / «Серп и молот» / «Еда и точка»** — бюджетный сегмент;
  для них раздел «что заказать» важнее, чем «бронь».
- **Жуклевичъ** и **Синкопа/Контрабанда** близки по поводу (вечер + музыка); при
  написании развести акценты, чтобы не дублировались.
