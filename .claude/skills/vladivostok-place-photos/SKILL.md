# Vladivostok place photos

Подбирает и вшивает фотографии в карточку места (модель `Attraction` из
[`src/data/types.ts`](../../../src/data/types.ts): поля `cover` и блок `gallery`).
Эталон — карточка `mayak-tokarevskogo.ts` + папка `src/assets/photos/mayak-tokarevskogo/`.

**Предусловие:** карточка уже существует как `.ts` в `src/data/attractions` — её
текст пишут скиллом **vladivostok-guide-card** и переводят в `.ts` через
**md-to-card-ts**. Этот скилл добавляет только **визуальный слой** поверх готовой карточки.

**Ключевой факт про инструменты:** ты видишь только **локальные** изображения
(инструмент чтения открывает JPG/PNG визуально). Веб-картинки «вслепую» оценить
нельзя — поэтому кандидатов сначала **скачивают локально**, и только потом смотрят.

## Правила (обязательные)

- **Источник — только свободные/официальные:** Wikimedia Commons (CC BY / CC BY-SA /
  PD) или официальные/пресс-фото. **Никаких Google-картинок / случайных сайтов.**
- **Атрибуция видимая:** CC BY требует показать автора. Кладём компактный кредит
  **прямо в `caption`**: `© Автор / CC BY X.X`. Плюс машинный `credits.json` в папке ассетов.
- **3–5 кадров на место, разнохарактерных** — чтобы широко показать объект
  (общий/герой + деталь + контекст/подход + другой ракурс/сезон).
- **Предпочтение — без людей.** Кадры, где люди в фокусе (позируют, толпа, купальники),
  **отбраковывать**. Крошечные далёкие фигуры допустимы, если больше нечего.

## Пайплайн

1. **Поиск + загрузка.** Запусти [`scripts/photofetch.sh`](scripts/photofetch.sh) `<slug> "<англ. запрос>" [limit]`
   — он ищет файлы на Commons, качает масштабированных (~1600px) кандидатов в
   `${PHOTO_CAND_DIR:-/tmp/photo-candidates}/<slug>/` и пишет `credits.json`
   (url, лицензия, автор, размеры). Запрос давай по-английски (на Commons так больше файлов).
2. **Анализ.** **Открой каждого кандидата** (инструмент чтения) и оцени по рубрике ниже.
3. **Отбор** 3–5 разнохарактерных, по возможности без людей. Отклонённые — с причиной.
4. **Вшивание:**
   - скопируй выбранные в `src/assets/photos/<slug>/` с осмысленными именами
     (`cover.jpg`, затем по сюжету: `kosa.jpg`, `machta.jpg`, …);
   - оптимизируй под веб: `convert IN -resize '1600x1600>' -quality 82 -strip OUT`;
   - создай `src/assets/photos/<slug>/credits.json` (см. эталон) с автором, лицензией и `source_url`;
   - в карточке: `import` каждого файла, поле `cover: { src, alt, caption }` и блок
     `{ kind: 'gallery', images: [{ src, alt, caption }] }` в подходящей секции
     (обычно «Что стоит рассмотреть»). `alt` — описание сцены; `caption` — сцена + кредит.
5. **Проверь:** `npx tsc --noEmit`. Новые импорты ассетов в уже запущенном Vite часто
   требуют **перезапуска дев-сервера** — предупреди пользователя.

## Рубрика отбора

| Критерий | Что проверяем |
|---|---|
| Объект | тот ли объект, узнаваем; **актуальность** (не устаревший вид — стройка, снесённое) |
| Люди | **без людей** в приоритете; в фокусе людей — отклонять |
| Композиция | свет, сезон, чистый передний план, без сильного наклона |
| Пропорции | cover — горизонтальный ~3:2/16:9; gallery — гибко |
| Качество | ≥1200px по ширине, без водяных знаков и артефактов |
| Лицензия | CC/PD/официальная; автор известен для атрибуции |

## `credits.json` (формат)

```json
{ "source": "Wikimedia Commons",
  "images": [{ "file": "cover.jpg", "author": "Имя", "license": "CC BY 2.0",
    "license_url": "https://creativecommons.org/licenses/by/2.0",
    "source_url": "https://commons.wikimedia.org/wiki/File:..." }] }
```

## Частые ошибки

- Взял фото не из свободного/официального источника → нельзя публиковать.
- Забыл кредит в `caption` — нарушение CC BY.
- Выбрал 3–5 однотипных кадров вместо разнохарактерных.
- Оставил кадр с людьми в фокусе, хотя были «пустые» варианты.
- Не оптимизировал (тяжёлые файлы) или положил кандидатов в репозиторий вместо ассетов.
- Устаревший вид подан как актуальный (сверяйся с текстом карточки).
